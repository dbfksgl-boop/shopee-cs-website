Shopee CS Automation

Order Monitoring and Seller Notification System

Product Overview

Shopee CS Automation is a seller-operated integration project designed to monitor Shopee orders and notify the seller about important order events.

The application is currently under development and testing using the Shopee Open Platform Sandbox.

Implemented Features

  • Retrieve orders using Shopee Open API v2.
  • Detect newly received orders.
  • Send new-order notifications via Telegram.
  • Refresh API access tokens.
  • Run scheduled monitoring using GitHub Actions.
  • Maintain encrypted token and notification state.

Planned Features

  • Multi-store order monitoring.
  • Multilingual customer service assistance.
  • Human review of complex customer enquiries.

Planned features are not currently available in the Sandbox demonstration.

How It Works

  1. The seller authorizes the application.
  2. The application retrieves order data.
  3. New orders are compared with saved records.
  4. The seller receives a Telegram notification.

Testing Status

Sandbox order retrieval and Telegram notification have been tested successfully. GitHub Actions execution and encrypted state updates have also been verified.

Production API access is pending Shopee Go-Live review.

Access and Availability

This is a private seller-operated integration, not a public customer-facing SaaS product. The application is not currently available for public registration.
